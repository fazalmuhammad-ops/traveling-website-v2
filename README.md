# Lanka Travellers - Traveling Website v2 🇱🇰

A modern, responsive Sri Lanka tour agency website built with semantic HTML5, CSS3, and JavaScript. Featuring high-resolution travel photography, dynamic tour package listings with prices in LKR, interactive booking forms, and responsive mobile-first layouts.

---

## 🌟 Pages & Features
- **[Home (`index.html`)](index.html)**: Hero showcase with Sri Lankan photography, interactive destination discovery tiles (Kandy, Galle, Sigiriya, Ella), key tour packages, and travel agency stats.
- **[Tour Packages (`packages.html`)](packages.html)**: Detailed itineraries, pricing in Sri Lankan Rupees (LKR), duration breakdowns, and direct booking integration.
- **[About Us (`about.html`)](about.html)**: Company vision, mission, story timeline (2015–2025), team member highlights, and responsible travel initiatives.
- **[Contact Us (`contact.html`)](contact.html)**: Interactive booking inquiry form with automatic package pre-selection via query parameters, office hours, and embedded location map.

---

## 🚀 Live Demo & Deployment
This website is completely static (no build step or backend required). You can view it live directly via GitHub Pages or deploy to Netlify / Vercel.

### Enable GitHub Pages:
1. Go to **Settings > Pages** in this repository.
2. Under **Build and deployment > Source**, select **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`.
4. Click **Save**. Your site will be live at:
   `https://fazalmuhammad-ops.github.io/traveling-website-v2/`
